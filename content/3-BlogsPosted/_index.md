###  [Blog 1 - If a Website Suddenly Gets 10,000 Visitors, What Happens?](3.1-Blog1/)
This blog explores how a website can handle a sudden increase in traffic, from a single EC2 instance to a scalable AWS architecture. It introduces concepts such as Scale Up, Scale Out, Load Balancing, Auto Scaling, Health Checks, CloudWatch, CloudFront, and security through a practical and easy-to-understand scenario. The blog focuses on understanding why each component is needed rather than simply learning AWS services by definition.
