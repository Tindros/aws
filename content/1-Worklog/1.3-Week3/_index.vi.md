### Kết quả đạt được trong tuần 3:

* Tiếp tục tìm hiểu các dịch vụ AWS và vai trò của chúng trong việc phát triển ứng dụng Serverless.

* Cải thiện kiến thức về:
  * Amazon RDS
  * AWS Lambda
  * Amazon API Gateway
  * Amazon Cognito
  * AWS Amplify
  * Amazon CloudWatch
  * IAM Roles và Permissions

* Tìm hiểu các yêu cầu và tiêu chí đánh giá của dự án thực tập.

* Bắt đầu xây dựng project proposal dựa trên yêu cầu của chương trình AWS FCAJ.

* Thiết kế kiến trúc hệ thống ban đầu cho dự án.

* Xác định các thành phần chính trong kiến trúc:
  * User / Web Browser
  * Amazon Cognito
  * Amazon API Gateway
  * AWS Lambda
  * Database
  * AWS Amplify
  * IAM Roles
  * Amazon CloudWatch

* Kiểm tra và cải thiện luồng dữ liệu giữa User, Frontend, API Gateway, Lambda và Database.

* Cải thiện hiểu biết về cách IAM Role cung cấp quyền cho các dịch vụ AWS truy cập và sử dụng các tài nguyên khác.

* Có thêm kinh nghiệm trong việc chuyển kiến thức từ Cloud Journey thành kiến trúc cho một dự án thực tế.
