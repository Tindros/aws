**This page** introduces my internship worklog and the activities completed during the **First Cloud AI Journey** program. The work was carried out over **12 weeks**, focusing on learning AWS Cloud, developing a Serverless application, and completing the Workshop documentation.

The main activities for each week are as follows:

**Week 1:** [Getting familiar with AWS and basic AWS services](1.1-week1/)

**Week 2:** [Learning IAM, VPC, EC2, Cloud9, S3, RDS, and AWS Lambda](1.2-week2/)

**Week 3:** [Learning and practicing AWS concepts related to databases and Serverless services](1.3-week3/)

**Week 4:** [Participating in an AWS-related event, continuing to learn about AWS Cloud, and defining the project direction](1.4-week4/)

**Week 5:** [Building the frontend with React + TypeScript and completing the basic application features](1.5-week5/)

**Week 6:** [Developing the Serverless Personal Expense Tracker and designing its architecture using AWS services](1.6-week6/)

**Week 7:** [Configuring Amazon Cognito, DynamoDB, Lambda, and API Gateway for the application](1.7-week7/)

**Week 8:** [Integrating the frontend with Cognito and API Gateway and completing the application's CRUD operations](1.8-week8/)

**Week 9:** [Testing the system, verifying JWT authentication, user authorization, and data isolation](1.9-week9/)

**Week 10:** [Completing the Workshop documentation, writing deployment instructions, and maintaining consistency between the Vietnamese and English versions](1.10-week10/)

**Week 11:** [Reviewing and updating the Workshop documentation, including Lambda, API Gateway, frontend, CloudWatch, and Amplify content](1.11-week11/)

**Week 12:** [Finalizing the documentation, checking images and paths, and preparing the project and Workshop for evaluation and submission](1.12-week12/)
