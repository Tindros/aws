### Week 1 Objectives:

* Become familiar with the internship environment and the First Cloud AI Journey program.
* Gain an overview of AWS Cloud and its main service categories.
* Understand the basic concepts of AWS account management, cost management, access control, networking, and cloud computing.
* Build a foundation in AWS knowledge to support future learning and the development of Data Science projects.

* Became familiar with the internship environment and the First Cloud AI Journey program.
* Gained an overview of AWS Cloud and its main service categories, including Compute, Storage, Networking, and Database.
* Completed the learning content on Creating Your First AWS Account and learned about the basic AWS account setup process.
* Understood the role of AWS Budgets in monitoring and managing AWS usage costs.
* Became familiar with AWS learning resources and support channels.
* Gained basic knowledge of AWS Identity and Access Management (IAM), including users, policies, and permissions.

* Built a foundation in AWS knowledge to support further learning and the development of Data Science projects during the internship.
